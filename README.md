## Возможности

- Система бекапов, возможность настроить автобекап и откатиться до нужной версии (Поддержка Github / База данных, В папку)
- Детальная настройка прав в белом списке, карантин (мера наказания)
- Логи - Посмотреть кто что нарушал, фильтры по действиями, дате , посмотреть конкретно человека (Так же логируется если ему допустим выдали какую то роль)
- Поддержка Telegram бота для уведомлений, а так же для подтверждения Включение/Выключение антикраша и освобождение из карантина

---

## 📦 Установка

Клонирования репозитория
```bash
git clone https://github.com/Crone720/Discord-Anticrash.git
```



## Создание Venv и установка зависимостей

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Запуск (Из окружения)
```bash
python3 main.py
```
